What can be paid?

The library itself remains open source. Payment is for work around the project, not for access to the public code.

  • Integration into an existing C/C++ service
  • Custom features and extensions
  • Debugging and performance investigation
  • Security and API design review
  • Priority support for a commercial project
  • Sponsored maintenance or roadmap work
